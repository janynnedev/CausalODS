# Evidências integradas para o artigo CausalODS

Este diretório reúne índices, matrizes e rascunhos derivados das
campanhas experimentais finais.

Os resultados originais não foram copiados ou modificados. Cada
evidência permanece em seu diretório canônico em `results/`.

## Estrutura

- `evidence/source-inventory.json`: inventário estruturado;
- `evidence/source-inventory.md`: versão legível do inventário;
- `evidence/asset-inventory.txt`: tabelas, figuras e relatórios
  disponíveis;
- `evidence/rq-evidence-matrix.md`: relação entre RQs, hipóteses e
  evidências;
- `report/integrated-results-draft.md`: rascunho técnico dos resultados;
- `provenance/`: commit, branch, data e ambiente da consolidação.

## Fontes principais

- E2E v1 × v2;
- sensibilidade à latência;
- explicações v1.1;
- robustez original;
- restart corrigido;
- robustez consolidada.

## Regra de preservação

Os arquivos originais das campanhas são somente leitura durante esta
etapa. Correções editoriais ou novos relatórios devem ser escritos
neste diretório integrado, nunca sobre os resultados originais.
